# ForgeOS documentation map

This directory is the canonical home for operational and historical documentation.

## Active docs

- `prd/` — current product requirement docs
- `deployment/` — active Vercel deployment guide and rollout steps
- `getting-started-production-system.md` — onboarding overview
- `content-planning/`, `content/`, `playbooks/`, `events/` — operating content system docs

## Archive docs

Historical status reports, review writeups, and implementation snapshots live under `archive/`:

- `archive/reviews/`
- `archive/status/`
- `archive/implementation/`

Archived docs are preserved for context but are not the current source of truth.
